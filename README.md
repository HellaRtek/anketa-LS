# Анкета · Логик Сфера

Офлайн-приложение для планшета: опрос сотрудников стендов на выставке («интервьюируем интервьюеров») и тех, кто работает без стенда. Основа — «Анкета МАРК».

## Файлы

- `index.html` — приложение целиком (собирается из `src/`, см. ниже)
- `sw.js` — офлайн-кэш; при каждом обновлении увеличить `VERSION`
- `manifest.webmanifest`, `icon-*.png`, `apple-touch-icon.png` — установка на экран «Домой»
- `fonts/` — Manrope и Unbounded (OFL), чтобы шрифты работали без интернета
- `src/head.html`, `src/app.js` — исходники; `./build.sh` собирает из них `index.html`

## Публикация на GitHub Pages

1. Создать репозиторий на GitHub «Логик Сферы» (например, `anketa`).
2. Загрузить все файлы из этой папки (кроме `src/` и `build.sh` — их можно тоже, они не мешают).
3. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты приложение доступно по адресу `https://<аккаунт>.github.io/<репозиторий>/`.

## Данные

Анкеты, фото и каталог экспонентов хранятся только на устройстве (localStorage и IndexedDB). В репозиторий и на внешние серверы ничего не уходит. Перенос между планшетами — резервной копией (.json) в разделе «Выгрузка».

Каталог экспонентов загружается на каждом планшете отдельно: «Выгрузка» → «Каталог экспонентов» → «Загрузить каталог (.xlsx)». Нужен лист с колонками «Компания», «Стенд», «Павильон / площадка», «Разделы выставки», «Сайт», «Страна», «№».
